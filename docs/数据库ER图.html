🔗 inventory ↔ orders

关系：应用层关联（非外键）
机制：通过 MENU 字典建立「菜品→食材」映射
示例：番茄炒蛋 → 鸡蛋×2 + 番茄×2

🛡️ 为什么不用外键？

原因：菜品与食材是多对多关系
设计：用 Python 字典 MENU 而非中间表
好处：改菜单只需改代码，不改表结构

🔒 库存一致性

扣减：下单时事务扣减
回滚：质检失败/降级时恢复
保证：SQLite 事务，出错自动 rollback
