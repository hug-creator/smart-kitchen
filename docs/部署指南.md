# 部署指南 — Render 上线智能餐厅

本指南帮你把项目部署到 Render（免费），获得公网可访问的地址。

## 一、准备工作（已完成 ✅）

- ✅ GitHub 仓库：`github.com/hug-creator/smart-kitchen`
- ✅ 代码已适配部署（`main.py` 支持 `$PORT`，模块级初始化数据库）
- ✅ 依赖已加 `gunicorn`

## 二、注册 Render（2 分钟）

1. 打开 [render.com](https://render.com)
2. 点 **Get Started** → **用 GitHub 账号登录**（会跳转 GitHub 授权）
3. 授权后进入 Render 控制台

> Render 免费版不需要信用卡，但首次创建 Web Service 时可能要求验证邮箱。

## 三、新建 Web Service（3 分钟）

1. 控制台点 **New +** → **Web Service**
2. 在仓库列表里找到 **smart-kitchen** → 点 **Connect**

3. 填写配置：

| 配置项 | 填什么 |
|---|---|
| Name | `smart-kitchen`（随便） |
| Region | 默认即可 |
| Branch | `main` |
| Runtime | **Python 3** |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `gunicorn main:web_app --bind 0.0.0.0:$PORT` |

4. **点 Advanced** → 添加环境变量（点 Add Environment Variable）：

| Key | Value |
|---|---|
| `DEEPSEEK_API_KEY` | 你的真实 key（本地 `.env` 里那个） |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` |
| `DEEPSEEK_MODEL` | `deepseek-v4-pro` |

> ⚠️ 环境变量填的 key 只会存在 Render 上，不会公开，安全。

5. 点 **Create Web Service**

## 四、等待部署 + 访问

- Render 会开始构建（约 2-5 分钟），完成后显示 **"Live"**
- 你会拿到一个地址，形如：`https://smart-kitchen-xxxx.onrender.com`
- 点开它，就是你的智能餐厅！

## 五、以后怎么更新代码

改完代码后，本地执行：

```bash
git add -A
git commit -m "优化了什么"
git push origin main
```

Render 检测到 GitHub 更新后**自动重新部署**，几十秒后线上就是新版本。

## 六、免费版的坑（提前知道）

| 坑 | 表现 | 影响 |
|---|---|---|
| **冷启动** | 闲置 15 分钟后休眠，下次访问要等 30-50 秒 | 演示时提前打开 |
| **SQLite 数据丢失** | 重启后库存/订单重置 | demo 无所谓 |
| **构建慢** | 首次部署 2-5 分钟 | 正常，耐心等 |

## 七、如果部署失败

常见原因：

| 报错 | 解决 |
|---|---|
| 依赖安装失败 | 检查 requirements.txt 是否完整 |
| 找不到 `main:web_app` | Start Command 拼写要完全一致 |
| 端口错误 | 必须用 `$PORT`，不要写死 5000 |
| 数据库报错 | 模块级 `init_db()` 已处理，重新部署即可 |
